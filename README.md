## Что было сделано

В рамках задачи подготовил постановку на разработку для комплекса «Управление уровнем доступа пользователей».

Проработал:

- 22 функциональных требования;
- 32 критерия приёмки;
- пользовательские роли и сценарии;
- бизнес-правила и ограничения;
- поиск, фильтрацию, добавление и редактирование пользователей;
- назначение ролей и сроков доступа;
- статусную модель;
- описание интеграций;
- матрицу трассировки требований;
- макеты интерфейсов в Figma.

Также подготовил документ «Описание автоматизируемых функций» с учётом требований ГОСТ 34.

## Результат

Сформирован комплект аналитических материалов, который можно использовать для передачи задачи в разработку и последующего тестирования.
